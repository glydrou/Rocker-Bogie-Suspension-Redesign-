# Rocker-Bogie-Suspension-Redesign-
## Overview
This repository contains documentation for a project focusing on a Rocker-Bogie Suspension design, used for extraterrestrial exploration. I already attempted this project during my actual semester and thought it would be a good idea to continue advancing the project. 
This document will go over the design/research, the fabrication and finally the proposal video (which I know a bit more about and will go over the editing process for that). 
Quick disclaimer: this is my first proper design project with an actual process; before, I mostly just messed around. I am also not a mechatronic or mechanical engineer, so this is a bit out of my comfort zone. I am not claiming this is the best design, or that this is my original design; it's just something I am using to further improve my CAD and fabrication skills.
